Byahero

A lighter, faster alternative to Google Maps for commuters — built with live weather updates and a stop-approaching alert so riders never miss their destination.

Source code

Project overview

Byahero is a lighter version of Google Maps with authentication and live weather updates — including a rolling 24-hour forecast so riders can plan around conditions, not just routes.

It was my first Android app. Building it meant learning APIs, persistent storage, networking, permissions, architecture, and clean-code practices from the ground up — originally built so my own family could replace Google Maps with something lighter.
