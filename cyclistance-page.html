Mobile Project

Cyclistance

Helps cyclists order roadside assistance in a few taps — the closest available helper arrives at your exact GPS location.

More on GitHub

The problem

Cyclists stranded with no fast way to call for roadside help.

Project overview

An Android app built to connect stranded cyclists with the nearest available helper. The requester's GPS location is shared directly with the responder, cutting out the back-and-forth of describing where you are.
